# Инициализация шардирования MongoDb

## Используя make

Выполните команду 

```shell
make init
```

Что произойдет:

1. Запуск проекта через `docker compose`
2. Инициализация сервера конфигурации MongoDb
3. Инициализация двух шардов
4. Инициализация роутера `mongos` на порту `27017` и шардирование коллекции
5. Заполнение коллекции документами

## Последовательная инициализация вручную

Запустите сервисы через 

```shell
docker compose up -d
```

Инициализируйте сервис конфигурации

```shell
./scripts/1-configsrv-init.sh
```

Инициализируйте шарды

```shell
./scripts/2-shards-init.sh
```

Инициализируйте `mongos`

```shell
./scripts/3-mongos-init.sh
```

Инициализируйте БД

```shell
./scripts/4-mongo-init.sh
```

## Тестирование шардирования

Через `make` запустите команду

```shell
make mongo-test
```

Команда покажет число документов в каждом шарде
